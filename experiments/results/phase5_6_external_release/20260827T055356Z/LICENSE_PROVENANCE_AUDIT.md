# License / Provenance Audit — Phase 5.6 Addendum

Performed prior to applying the requested licenses (MIT for benchmark/software
code, CC BY 4.0 for the dataset) and before any publication. This audit
determines whether any upstream source that fed the Phase 5.2 canonical
dataset or the Phase 5.3/5.4 benchmark code restricts redistribution in a way
that would block applying these licenses.

## Scope

Everything actually redistributed in the two release packages under
`experiments/results/phase5_6_external_release/20260827T055356Z/release/`:
`release/dataset/data/all_records.jsonl` (3,106 records) and all files under
`release/benchmark/`.

## Method

1. Read `dataset_metadata.json`'s `source_file_sha256` map to identify the
   exact upstream Phase 4 artifacts the canonical dataset was built from.
2. Read the actual record content (`agent_output` field) across all three
   task families to determine exactly what data is stored per record.
3. Read `data/real_model_tasks/generate_corpora.py` (the corpus generator
   named in the dataset's own provenance chain) to determine whether the
   sentiment/QA evaluation text is copied from an external benchmark or
   authored by this project.
4. Checked the two Hugging Face model checkpoints' license terms directly
   (model cards, fetched 2026-08-27) for any restriction on redistributing
   derived inference outputs.
5. Confirmed no `LICENSE`, `NOTICE`, or restrictive-terms file exists in any
   upstream directory this project's own code touches.

## Findings

### 1. Dataset record content — no copied third-party text

Inspected sample records from all three `agent_task` families directly:

- `arithmetic_self_consistency`: stores only a generated arithmetic
  expression (e.g. `"((((20 - 4) - 7) - 1) * 3)"`), the model's sample
  answers, majority vote, and a correctness flag. The expression is
  generated by this project's own code (seeded, deterministic) — not sourced
  from any external corpus.
- `sentiment_softmax_margin`: stores only `model_checkpoint` (a string name),
  `predicted_label`, `template_label`, and `softmax_margin` — a derived
  confidence score. **No input sentence text is stored in the canonical
  dataset record itself.**
- `extractive_qa_span_logit`: stores only `model_checkpoint`, `gold_answer_span`,
  `predicted_span`, and `span_logit_confidence` — again, no source passage
  text is stored in the record.

Conclusion: the redistributed dataset contains no raw third-party text at
all, whether from a licensed benchmark (GLUE/SST-2, SQuAD) or otherwise —
only project-generated identifiers/expressions and model-derived numeric/
label outputs.

### 2. Corpus generation — self-authored, not copied from GLUE/SST-2/SQuAD

`data/real_model_tasks/generate_corpora.py`'s own docstring states the
design reasoning directly: *"Why hand-built/templated corpora instead of
downloading a standard benchmark (GLUE/SST-2, SQuAD): the model weights
already required one download-permission round-trip with the user; a second
dataset download would need a second one."* The sentiment templates
(`POSITIVE_TEMPLATES`/`NEGATIVE_TEMPLATES`/`SUBJECTS`/adjective lists) and QA
templates are hand-authored by this project, deterministically seeded
(`CORPUS_SEED = 4600`), not sourced from any external dataset. There is no
GLUE, SST-2, or SQuAD file anywhere in this repository's dependency chain for
the canonical dataset.

### 3. Third-party model checkpoints — Apache-2.0, outputs not restricted

Two Hugging Face checkpoints were run locally to produce the derived scores
stored in the dataset:

| Checkpoint | License | Redistribution restriction on derived outputs |
|---|---|---|
| `distilbert-base-uncased-finetuned-sst-2-english` | Apache-2.0 | None found. Apache-2.0 governs the model weights/code; the model card states no restriction on sharing inference outputs (predictions/confidence scores). |
| `distilbert-base-cased-distilled-squad` | Apache-2.0 | Same — Apache-2.0, no output-redistribution restriction found on the model card. |

Neither model's weights are redistributed by this project — only two
open-licensed, permissive checkpoints were run locally, and only their
derived numeric outputs (already summarized above) are stored in the
dataset. Apache-2.0 is a permissive license that does not impose share-alike
or output-restriction terms; using a model for inference and publishing the
resulting scores is standard, unrestricted practice under this license, and
attribution is given in this package's `LICENSE`/`DATASET_CARD.md`.

### 4. Historical Phase 4 external datasets — confirmed NOT in the canonical dataset

Earlier project phases (Phase 3, and Phase 4's real-data track) used real
operational datasets: AgentRx, the Alibaba PAI GPU2020 cluster trace, and
CCF AIOps 2020. These have their own upstream terms and are **not** part of
the Phase 5.2 canonical dataset or this release: Phase 5.2's own construction
report already documented that these sources are aggregate-only (no
per-episode join key) and were explicitly excluded from record-level
ingestion. Confirmed again here directly against `dataset_metadata.json`'s
`source_file_sha256` map — it lists only Phase 4.4/4.5/4.6-4.10 *evaluation
result* files (this project's own generated evidence), not any raw
AgentRx/Alibaba/AIOps source file. Those three datasets' own licensing terms
are therefore out of scope for this release and impose no restriction on it.

### 5. Benchmark code — fully authored by this project

`src/benchmark/` (all modules: `dataset_loader.py`, `validation.py`,
`splits.py`, `leakage.py`, `metrics.py`, `baselines.py`, `ablations.py`,
`tasks.py`, `registry.py`, `reporting.py`, `reproducibility.py`, `runner.py`,
`status.py`, `constants.py`, `ids.py`) was written during Phases 5.3-5.5 of
this project. No code was copied from another licensed project. Standard
Python dependencies (`requirements.txt`) are separately licensed by their own
maintainers and are not redistributed as part of this codebase — a user
installs them independently via `pip install -r requirements.txt`, exactly as
intended by their own licenses.

## Conclusion

**No upstream source imposes a redistribution restriction that blocks
applying MIT (benchmark/software code) or CC BY 4.0 (dataset).** The audit
found:

- Zero raw third-party dataset text in the canonical dataset.
- Zero copied benchmark corpora (GLUE/SST-2/SQuAD) — all evaluation text is
  self-authored and templated.
- Two Apache-2.0 model checkpoints used only for local inference, with their
  derived outputs (not weights) stored — no restriction found on this use.
- The three historical real-operational-datasets (AgentRx/Alibaba/AIOps) are
  confirmed absent from the canonical dataset and therefore impose no
  constraint on this release.
- All benchmark code is self-authored.

**Audit result: PASS.** Proceeding to apply the requested licenses.
